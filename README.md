# Intelligent Matching Algorithm

This repository contains a Python implementation of a simple, intelligent matching algorithm.

This model uses gradient descent to learn the optimal weights (alphas) for a set of features (e.g., age similarity, shared interests) to calculate a compatibility score. The matching.ipynb notebook demonstrates how to train the algorithm on labeled examples of good matches (1) and bad matches (0) to find the best feature importance.

For a detailed write-up on the algorithm and its derivation, check out the full [blog post](https://mateolafalce.github.io/2025/A%20Generic%20Intelligent%20Matching%20Algorithm/A%20Generic%20Intelligent%20Matching%20Algorithm.html)
